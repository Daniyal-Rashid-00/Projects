## 🎨 Design & Engineering Philosophy

Many modern portfolios rely on heavy abstraction layers (like React/Next.js) for static content. I chose to build my portfolio closer to the metal to ensure blazing-fast load times and to showcase my ability to engineer complex UI/UX without relying on component libraries.

### Key Highlights:
- **Zero-Dependency Architecture:** No massive `node_modules` or complex build tools required. The site serves raw, minified assets to the browser.
- **Complex Vanilla CSS:** Showcases advanced CSS techniques including Flexbox, CSS Grid (`GridScan.css`), complex pseudo-selectors, and custom CSS variables for maintainable theming.
- **Micro-Animations & Interactions:** Implemented fluid hover states, scrolling animations, and dynamic DOM manipulations purely via vanilla JavaScript.
- **Fully Responsive:** Painstakingly crafted with mobile-first media queries to ensure the site looks and performs flawlessly across mobile phones, tablets, and ultra-wide desktops.

## 🚀 Running Locally

Because there are no complex build tools, running this locally is incredibly easy:

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/daniyal-portfolio.git
cd daniyal-portfolio
```
2. Open `index.html` directly in your browser.
*(Alternatively, use the VS Code Live Server extension for hot reloading).*
